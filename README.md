# SqAr — Autonomous Agent Engine

SqAr is an intelligent agentic orchestration framework built on NVIDIA Nemotron models hosted on Nebius Token Factory and Nebius AI Cloud.

## Highlights
- **High-Throughput Reasoning:** Leverages NVIDIA open-source foundation models.
- **Nebius Token Factory:** Low-latency serverless model routing.
- **Autonomous Execution:** Breaks high-level tasks into self-verifying agent workflows.

## Setup & Running
```bash
git clone [https://github.com/](https://github.com/)<YOUR_USERNAME>/SqAr.git
cd SqAr
pip install -r requirements.txt
export NEBIUS_API_KEY="your_nebius_key"
python main.py
